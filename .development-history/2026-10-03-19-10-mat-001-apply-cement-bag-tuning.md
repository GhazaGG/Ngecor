# MAT-001 Apply Cement Bag Tuning (Batchmode) and PlayMode Tests

## Task summary
Apply the cement bag feel changes from `2026-10-03-18-30-mat-001-cement-bag-feel.md` to the prefab and physic material through the Unity API, then verify them with automated PlayMode tests. The user chose batchmode with Unity closed.

## Relevant previous context
- `2026-10-03-18-30-mat-001-cement-bag-feel.md`: added `CementBag.cs` and listed the Inspector steps. The prefab root carried a ~4 degree tilt, was too thick (0.3 m), and had a fixed center of mass.
- Issue #15 acceptance criteria: stack of 5 settles, no ball-like bounce, Rigidbody sleeps.

## Changes made
- Temporary editor script `Assets/Game/Scripts/Editor/CementBagSetup.cs`, run via `-executeMethod`. It deleted itself with `AssetDatabase.DeleteAsset` after running and is no longer in the repo.
  - `CementBag.prefab`: root position/rotation zero, scale (0.7, 0.14, 0.45), `CementBag` component added, Rigidbody mass 40, linear damping 0.2, angular damping 1.5, Interpolate, Continuous Speculative.
  - `CementBag.physicMaterial`: static 0.9, dynamic 0.75, friction combine Maximum, bounce combine Minimum.
- New PlayMode tests `Assets/Game/Tests/Material/CementBagTests.cs`:
  - `StackOfFiveSettlesAndSleeps`: 600 fixed steps; the top bag drifts < 0.1 m and all bags sleep.
  - `DroppedBagDoesNotBounce`: dropped from 2 m tilted; upward velocity after landing < 0.5 m/s; ends at rest.
  - `UprightBagIsBottomHeavy`: the world center of mass of an upright bag sits > 0.05 m below its pivot.
- `docs/MAT-001-Cement-Bag-Test-Cases.md`: updated the baseline configuration reference.

## Technical decisions
- No text edits to the prefab or asset. All serialized changes went through Unity 6000.3.25f1 in batchmode.
- `Dev_Ghaza.unity` was not touched (it has uncommitted user edits). Its 6 CementBag instances override rotation and still carry the old tilt.

## Verification performed
- `setup.log`: "CementBagSetup: prefab and physics material updated.", exit 0. Read-only inspection of the prefab and material YAML confirmed the values.
- PlayMode run (`-runTests -testPlatform PlayMode`), exit 0: 36/36 passed, including the 3 new CementBag tests and all existing Interaction/Material/Player tests.
- Not verified: the tests were not run against the old prefab values, so it is unproven that they would have failed before. Subjective feel and the pillow mesh visual were not observed; they need a manual playtest in the Editor.

## Final result
Prefab and physic material tuned. Automated checks for stacking, sleeping, no bounce, and bottom-heavy pass.
