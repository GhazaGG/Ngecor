Project decisions select Windows PC, first-person keyboard/mouse, Unity Input System, and native `CharacterController`. ## Changes made
- Added yaw-relative movement with normalized diagonals, mouse yaw/pitch, gravity, Inspector tuning, and native collision response.
- Added explicit local ownership. Player prefabs default to non-local; `SetLocalPlayer(bool)` lets the runtime owner configure input, and the Playground scene explicitly marks its single player instance as local.
- Added eight Play Mode tests, including local/non-local input behavior and wall/ramp movement. Test fixtures use coordinates separate from Playground geometry.
- Documented the control bindings, test folder convention, implementation plan, and acceptance status.
- Created PR #48: https://github.com/GhazaGG/Ngecor/pull/48

## Technical decisions
Reused the installed Input System actions and native CharacterController. No package or shared input-actions asset was changed. Non-local players do not enable or read Move/Look actions; local ownership can be assigned before or after activation. The Playground instance is explicitly local. Unrelated Unity-generated changes to `ProjectSettings/VersionControlSettings.asset` and `ProjectSettings/SceneTemplateSettings.json` were left out of the commit and PR.
